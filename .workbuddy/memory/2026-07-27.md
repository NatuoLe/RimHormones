## 击飞技能（Knockback Ability）— 新增

### 设计
- **主动技能**：征召后选中敌人释放，近战距离（1.9格）
- **短距击飞（2-3格）**：沿 caster→victim 连线方向推飞
- **落地效果**：眩晕 60 tick + 钝击伤害 5（穿甲 0.1）
- **冷却**：AbilityDef.cooldownTicksRange = 1500~1800 tick

### 技术实现
- `PawnFlyer_Knockback : PawnFlyer`：重写 RespawnPawn()，落地时施加眩晕+伤害+尘土特效
- `CompAbilityEffect_Knockback : CompAbilityEffect`：计算推飞方向、从远到近找合法落地格（JumpUtility.ValidJumpTarget）、创建 PawnFlyer
- `CompProperties_AbilityKnockback`：可 XML 配置 pushDistance/impactDamage/armorPenetration/stunTicks

### 获得方式
- 新增 TraitDef `ExplosivePower`（爆发力）：体魄+2，闪避+5%，冲突 Anorexic/Slender
- `HarmonyPatches.cs` Pawn_SpawnSetup 中检测 ExplosivePower → 自动授予 Hormones_Knockback 技能
