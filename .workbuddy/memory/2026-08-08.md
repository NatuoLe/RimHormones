## 新特性「快感缺失」实现方案（正面心情全部归零）
- 用户决策：载体=**Hediff**（如 CortisolAnhedonia）；实现=**Harmony 扩展**；触发=**独立手动控制**（不随神经衰弱自动挂，提供 Add/Remove helper 由外部决定时机）。
- **关键纠错**：`baseMoodEffect` 在 **ThoughtStage** 上（`BaseMoodOffset => CurStage.baseMoodEffect`），**不在 ThoughtDef** 上。所以"正面心情"判定不能用 `def.baseMoodEffect`，应直接用 `Thought.MoodOffset()` 的运行时返回值 `__result > 0f`，更精准且覆盖 worker/curve 类。
- 原生屏蔽机制 `ThoughtUtility.ThoughtNullified(pawn, def)` 按 **具体心情 def** 枚举（def.nullifyingTraits / hediffSet.ThoughtNullifyingHediff），**无法表达"所有正面心情"**，故走 Harmony 扩展。
- **推荐实现**：Harmony postfix patch `Thought.MoodOffset()`（基类）+ 主要 override 子类（Thought_Memory / Thought_MemorySocial / Thought_SituationalSocial / Thought_MemorySocialCumulative），`if (__result > 0f && AnhedoniaLogic.HasAnhedonia(__instance.pawn)) __result = 0f;`。`__instance.pawn` 为 Thought 实例字段（MoodOffset 内即用），可直接取；负/零不动。
- 新建 `AnhedoniaLogic.cs`：`HasAnhedonia(pawn)`(HasHediff CortisolAnhedonia) + `Add(pawn)`/`Remove(pawn)`（守卫式挂摘，供独立触发）。
- XML：`Hediff_Cortisol.xml` 新增 `CortisolAnhedonia`（纯标记 stage，不修改属性；独立手动控制故不设 disappearsAfterTicks）。
- 纯 C#+新 XML，需编译部署；未改旧 public 签名，CE 无需重编。尚未落地，等用户确认「按此逻辑实现」。
