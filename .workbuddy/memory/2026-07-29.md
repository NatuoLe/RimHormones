## 拆分 SensoryOverload → VisualStrain(眼) + AuditoryStrain(耳)
- 原因：原 SensoryOverload 一个 Hediff 同时改 Sight(眼)+Hearing(耳)，但 Hediff 只能附着单一部件，会出现"挂在眼睛上却降听力"的解剖错位。用户要按器官拆开（视觉疲劳 vs 耳鸣是两个）。
- XML（Hediff_StrainPool.xml）：删 SensoryOverload，新建两个：
  - `VisualStrain`（视觉过载→Eye，只改 Sight）：视觉疲劳(0,Sight×0.90)→眼肌痉挛(0.4,×0.75)→视网膜损伤(0.75,×0.50)，painOffset 0.02/0.08/0.15。
  - `AuditoryStrain`（听觉过载→Ear，Hearing+Consciousness，内耳前庭联动意识）：耳鸣(0,Hearing×0.85)→听觉过敏(0.4,×0.65+Consc×0.95)→听力损伤(0.75,×0.40+Consc×0.80)。
  - 两者恢复均沿用 SeverityPerDay -0.29。
- C#（AdrenalineLogic.cs HediffTargetParts）：删 SensoryOverload→{Eye,Ear}，加 VisualStrain→{Eye}、AuditoryStrain→{Ear}。字典 private 不影响 CE 包签名，无需重编 CE。二者本就未入战斗抽取池，抽取列表无需改。
- Excel（损伤Hediff与触发逻辑.xlsx）：总览 A11 拆成视觉/听觉两行；阶段详情 A27-32 拆成两组各三阶段(重建合并 A27:A29/A30:A32)；触发逻辑"未入池"文本 SensoryOverload→VisualStrain/AuditoryStrain。
- 编译 0 err 0 warn；XML+DLL(65024B,22:51)均已部署 Steam（本次游戏未运行，一次成功）。重启游戏生效。

## 新增：统一飘字管理器 FlyTextMgr（对象池 + 池化 StringBuilder + 可替换颜色）
- 需求：飘字不再散落各处直接 new，改由一个管理器 FlyTextMgr 飘出；每次字符串拼接与飘字 UI 对象都从对象池获取；劳损/肾上腺素透支的 Hediff 触发都要飘字；颜色可替换。
- 新建 `Source/UI/FlyTextMgr.cs`（namespace Hormones.UI）：
  - `FlyTextEntry`：可复用飘字单元（worldPos/text/color/ageSec/lifeSec/velZ/active），Reset() 归还前清空。
  - `FlyTextMgr : GameComponent`（游戏自动反射实例化，构造签名 `FlyTextMgr(Game)`；无需手动注册）。单例 Instance 在 FinalizeInit/LoadedGame/StartedNewGame 赋值。

  - 入口：`Push(Pawn, string, Color)` / `Push(Pawn, StringBuilder, Color)`(自动归还SB) / `PushAt(Vector3, string, Color)`。
  - 推进：`GameComponentUpdate` 用 Time.deltaTime 上浮(RiseWorldZPerSec 0.9/s)+计龄，到寿命(3s)回收；`GameComponentOnGUI` 仅 Repaint 且非世界视角时自绘：cam.WorldToScreenPoint/Prefs.UIScale + y=UI.screenHeight-y，按 FadeStartFrac 0.45 起算 alpha，Widgets.Label 居中。
