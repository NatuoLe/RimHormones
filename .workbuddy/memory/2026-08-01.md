## 修复玩家报错 MissingMethodException: AdrenalineLogic.TryApplyOverexertDamage(Pawn)

**玩家报错**：`Exception ticking DMS_Mech_Soldat ... System.MissingMethodException: Method not found: void Hormones.AdrenalineLogic.TryApplyOverexertDamage(Verse.Pawn)`

**根因（git 实锤）**：
- 0.4.2（commit 8a46cd4）给 `TryApplyOverexertDamage` 加了 `float chanceMultiplier = 1f` 可选参数。
- C# 可选参数是编译期语法糖：加参后 IL 层"单参数签名"不复存在。
- 旧版 RimHormonesCE.dll 编译时固化调用单参签名 → 新本体 + 旧 CE 包 = JIT 时抛 MissingMethodException。
- DMS 机械体只是触发者（CE 近战动词 patch 被 JIT），非元凶；物种守卫也挡不住（异常发生在调用方 JIT 编译时，早于方法体执行）。
- 教训：公开发布的 mod，改 public 签名 = 二进制破坏性变更，光重编译自家 CE 包不够（玩家手里有旧 DLL 残留），**必须留兼容垫片**。

**修复（双保险）**：
1. 本体 `AdrenalineLogic.cs` 补回单参重载作垫片：`TryApplyOverexertDamage(Pawn)` 转发到 `TryApplyOverexertDamage(Pawn, float)`（去掉了双参版本的默认值，改为两个显式重载，避免解析歧义）。注释标注"勿删"。
2. 本体编译 0 错 0 警 → cp 到 Steam Mods/Rim-Hormones/Assemblies/ + 同步到 RimHormonesCE/Refs/。
3. CE 补丁包重编译 0 错 0 警 → cp 到 RimHormonesCE/Assemblies/ + Steam Mods/RimHormonesCE/Assemblies/（MD5 863eff5a… 一致）。

**待办**：下次发布 Workshop 时本体与 CE 包一起推；玩家只需更新本体即可让旧 CE 残留也恢复（垫片兜底）。

## 调研：器官 HP 归零的后果（源码已核实）

- **用户提醒：查 RimWorld 游戏源码/Def 优先用 `mcp__rimsage__*` MCP**（search_source 正则搜反编译源码、read_csharp_symbol 读类型/方法、search_defs/get_def_details 查 Def、read_file 按路径读），比本地搭反编译快得多。本地 ICSharpCode.Decompiler 方案（/tmp/probeproj 已配好，PackageReference 9.1.0.7988）作为后备。
- **摧毁路径**（HediffSet.cs:342）：伤害结算加 injury 时若 `GetPartHealth(part)==0` 且非 corePart → 自动加 `MissingBodyPart` hediff（Hediff_MissingPart），`IsFresh=!该部件装过人造假体`；PostAdd 里给所有子部件递归加 MissingPart（IsFresh=false）。
- **MissingBodyPart def**：injuryProps bleedRate 0.12 / painPerSeverity 0.0125、tendable。但 `IsFreshNonSolidExtremity` 要求 depth≠Inside → **内部器官被毁时 MissingPart 本身不再额外出血/疼痛**（出血疼痛由造成摧毁的那个伤口承担）。新鲜期 90000 tick(1.5天)或包扎后变陈旧。ShouldRemove=false 永不自愈，只能靠移植/再生舱。
- **死亡判定 ShouldBeDead 顺序**：①hediffSet.HasPreventsDeath 免死 → ②任一 hediff CauseDeathNow（IsLethal 且 Severity≥lethalSeverity，如失血/感染 100%）→ ③ShouldBeDeadFromRequiredCapacity：lethalFlesh(血肉)能力 `!CapableOf`（CapableOf = GetLevel > minForCapable，五大器官能力 minForCapable 默认 0 → **能力≤0 即死**）→ ④corePart(躯干)效率 ≤0.0001 → ⑤总伤 severity ≥ 150×HealthScale。
- **意识耦合精确公式**（PawnCapacityWorker_Consciousness 反编译）：意识 = 脑效率 − 疼痛惩罚(pain 0.1→1 映射 0→0.4 绝对值)；再 `Lerp(向 num×min(泵血,1), 0.2)` → `Lerp(向 num×min(呼吸,1), 0.2)` → `Lerp(向 num×min(过滤,1), 0.1)`。即单肺毁(呼吸50%)→意识×0.9；双肾毁(过滤50%)→意识×0.95。
- 各器官归零后果：心→死；脑→死(未毁则几乎必永久疤)；单肺→呼吸50%/意识-10%；双肺→死；单肾→过滤75%；双肾→过滤50%/意识-5%；双肾+肝→死；肝→过滤50%+代谢50%（可活）；肝+胃→死；胃→代谢50%（可活）。

## 新功能：劳损储备过低禁止重体力工作（2026-08-01）
