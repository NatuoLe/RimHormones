## 修复第四批 XML 报错（ingestible 块：nutrition 字段 + foodType=Fluid + NeverForNutrition）
- 现象：①`<nutrition>0</nutrition> doesn't correspond to any field in type IngestibleProperties`；②`Exception parsing RimWorld.FoodTypeFlags from "Liquid"`（仅水瓶）。
- 根因（用 rimsage 查 RimWorld 1.6 源码确认）：`IngestibleProperties` **没有 `nutrition` 字段**——营养值来自 ThingDef 的 `Nutrition` stat（写在 `<statBases><Nutrition>0</Nutrition></statBases>`，`CachedNutrition` 走 `parent.GetStatValueAbstract(StatDefOf.Nutrition)`）。`FoodTypeFlags` 液体的合法值是 **`Fluid`(=4)**，不是 `Liquid`。`Plant`/`AnimalProduct` 均合法。
- 隐藏 config 报错（不修会黄字）：`IngestibleProperties.ConfigErrors` 规定 `Nutrition==0` 时 `preferability` 必须为 `NeverForNutrition`，否则报 "Nutrition == 0 but preferability is X instead of NeverForNutrition"。
- 修复（4 件 MEE 物品）：删 ingestible 内 `<nutrition>0</nutrition>`；`<preferability>DesperateOnly</preferability>`→`NeverForNutrition`；水瓶 `foodType>Liquid`→`Fluid`；statBases 显式加 `<Nutrition>0</Nutrition>`。源+部署副本 XML 校验通过、`NeverForNutrition`/`Fluid` 已就位、无残留 `nutrition` 字段。纯 XML 改动，无需重编 DLL；规则已写入 MEMORY.md「ThingDef ingestible 写法铁律」。
