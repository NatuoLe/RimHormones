## 肾上腺素模块「体魄 P」测试用例（用户"有了吗"追问补完）
用户此前要求"以体魄 P 为变量的测试用例"。本回合补全交付。

### 交付物
- `Dev/Adrenaline_Physique_TestCases.md`：测试矩阵 + 断言 + 游戏内验证步骤 + 已知缺口。

### 核心结论（已用代码核实）
- 体魄阈值：`<8` → physiqueMod=0.5（B路Stat效果减半）；`8≤P<13` → 1.0；`P≥13` → 豁免，MeleeHitReduction 归零（其余不变）。
- **A 路（capacityMods/painFactor，XML 静态）不受 P 影响**；**B 路（MoveSpeed/MeleeDamage/MeleeDodge/MeleeHit/Metabolism，Harmony 注入）受 P 影响**。
- 已知缺口：① `restFallFactor` 已注释、未走 Need_Food → 休息维度完全不生效；② `P≥13` 视听豁免在 C# 内惰性（容量由 XML 静态施加，无净效果）。
- 数值基准（High 档）：P≥8 时 MoveSpeed×1.1 / MeleeDmg×1.2 / Dodge×1.12 / Metab×1.4；P<8 全减半；P≥13 MeleeHit×1.0。

## Combat Extended 兼容性分析（体魄+肾上腺素）
- CE 模组：workshop 2890901044，纯 `CombatExtended.dll`（无源码）。用独立 net48 反射工程 dump 类继承（`C:\Users\zhou\AppData\Local\Temp\ceinspect`，一次性，可删）。
- **关键继承结论**：
  - `Verb_MeleeAttackCE : RimWorld.Verb_MeleeAttack`，但 **override TryCastShot()**，且命中改用自有 `GetHitChance`/`GetDodgeChance`（不走原版 GetNonMissChance）。
  - `Verb_LaunchProjectileCE : Verse.Verb`（**不继承** Verb_LaunchProjectile），远程完全脱离原版投射物体系；伤害走 `ProjectileCE.Impact` → `ArmorUtilityCE.GetAfterArmorDamage`。
  - CE **不改** WorkSpeedGlobal/MoveSpeed/MeleeDamageFactor/MeleeDodgeChance/MeleeHitChance 这些 StatDef，也不改 StatWorker.GetValue / Need_Food。
- **我方 patch 存活判定**：StatWorker.GetValue（体魄+肾上腺 Stat 效果）✅ 全活；Need_Food ×2 ✅；Pawn.Tick ✅；Thing.TakeDamage ⚠️部分（近战活，CE 弹道可能漏）；`Verb_MeleeAttack.GetNonMissChance` ❌（CE 自算命中）；`Verb_MeleeAttack.TryCastShot` ❌（子类 override，基类 patch 不触发）；`Verb_LaunchProjectile.TryCastShot` ❌（CE 远程不继承它）。
- **核心问题**：CE 下肾上腺素"产生"入口几乎全废 → 肾上腺涨不起来；体魄近战命中加成也失效。Stat 效果本身都活着。
- **方案**（写入 `Dev/CE_Compatibility_Plan.md`）：A=用 `AccessTools` 条件 patch 重挂 `Verb_MeleeAttackCE.TryCastShot`/`Verb_LaunchProjectileCE.TryCastShot`（复用 AdrenalineProducer.OnAttack/OnHit）；B=postfix `Verb_MeleeAttackCE.GetHitChance` 恢复体魄命中加成；全程反射不硬引用 CE.dll，About.xml 加 `loadAfter CETeam.CombatExtended`。
