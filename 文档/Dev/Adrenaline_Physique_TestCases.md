# 肾上腺素模块 × 体魄(P) 测试用例

> 目标：用**体魄等级 P** 作为唯一变量，验证肾上腺素 4 档浓度下各效果的最终数值，
> 确认体魄修正（`physiqueMod`）与豁免（`exempt`）逻辑符合设计。
> 数值由 `Dev/adr_test.py` 生成（忠实复刻 `AdrenalineLogic.CalculateAdrenalineEffects` + `PhysiqueDefine`）。

## 1. 测试变量与常量

| 项 | 含义 | 取值 |
|---|---|---|
| `P` | 体魄等级（变量） | 0 ~ 20 |
| 浓度档 | Adrenaline Hediff Severity 区间 | Dormant <0.15 / Low <0.5 / Medium <0.75 / High ≤1.0 |
| `PenaltyThreshold` | 体魄惩罚阈值 | **8** |
| `ExemptionThreshold` | 体魄豁免阈值 | **13** |
| `PenaltyFactor` | 低体魄缩放因子 | **0.5** |

**派生规则（来自代码）：**
- `physiqueMod(P) = 0.5`（当 `P < 8`），否则 `= 1.0`
- `exempt(P)   = true`（当 `P ≥ 13`）

## 2. 应用路径（关键！决定 P 影响哪些效果）

| 路径 | 效果项 | 施加方式 | 是否受 P 影响 |
|---|---|---|---|
| **A 路（容量/忍耐度）** | Sight/Hearing/Breathing/Consciousness/BloodFiltration 偏移、painFactor | `Hediff_Adrenaline.xml` 的 `capMods` / `painFactor`（静态） | ❌ **不受 P 影响**，全 pawn 一致 |
| **B 路（Stat）** | MoveSpeed、MeleeDamageFactor、MeleeDodgeChance、MeleeHitChance、Metabolism(饥饿) | `HormonesLogic` 的 Harmony patch，读取 `CalculateAdrenalineEffects` | ✅ **受 P 影响**（×physiqueMod；MeleeHit 在 `P≥13` 归零） |

> ⚠️ 注意：`CalculateAdrenalineEffects` 内部把 `VisionReduction/HearingReduction` 在 `P≥13` 时置 0，
> 但**容量由 A 路 XML 静态施加**，C# 里的归零对容量无实际作用——即“视听豁免”目前是惰性逻辑。
> 真正受 P 影响的只有 B 路 5 项（上表）。

## 4. 断言（Pass/Fail 判定）

对每个 `(浓度档, P)` 组合，应成立：

1. **低体魄惩罚**：`P ∈ {0,3,5,7}` 时，所有 B 路倍率 = 基准 ×0.5（即相对 `P≥8` 减半）。
   - 例：High 档 MoveSpeed → 1.10（P≥8）vs 1.05（P<8）✔
2. **豁免断点**：`P ≥ 13` 时 `MeleeHit ×= 1.0000`（命中惩罚归零），其余 B 路项不变。
   - 断点验证：`P=12` MeleeHit=0.9200 vs `P=13` MeleeHit=1.0000 ✔
3. **惩罚断点**：`P=7` 走 0.5 缩放，`P=8` 走 1.0 缩放，两者其余项有明显跃升。
4. **A 路独立于 P**：`capMods` / `painFactor`（Sight/Hearing/Breathing/Consciousness/BloodFiltration）无论 P 多少均固定为 XML 值（Low: Sight/Hearing −0.08, Breath/Consc/Blood +0.03~0.07, painFactor 0.93；Medium/High 见 `Hediff_Adrenaline.xml`）。
5. **Dormant 档**：`S < 0.15` → 全部效果为 0（无加成/无惩罚），与 P 无关。

## 5. 游戏内验证步骤

1. 开启 Dev 模式，用 `Adrenaline` Hediff 直接给目标 pawn 设 Severity（0.2 / 0.6 / 0.9 对应低/中高/高）。
2. 用 `Health` 面板或 `Inspect` 核对移动速度、近战命中（开战后观察）、饥饿速率。
3. 改 pawn 的 Physique 技能等级（或加/减特质偏移）制造 `P<8` 与 `P≥13` 两组。
4. 对比 `P=7` vs `P=8`（应见 B 路效果跃升）与 `P=12` vs `P=13`（命中惩罚消失）。
5. 重跑 `python Dev/adr_test.py` 复算基准值，与实测比对。

## 6. 已知缺口 / 待办

- **休息维度完全不生效**：`restFallFactor` 已在 XML 注释禁用，且未走 `Need_Food`，`RestMultiplier` 当前无实际作用。
- **视听豁免惰性**：`P≥13` 时 C# 把 Vision/Hearing 置 0，但容量来自 XML 静态，无净效果。若要让体魄影响视听，需改成动态 capacity 或移除该惰性分支。
- `MeleeHitReduction` 降 3：现行 High 档基准 −0.08（绝对值），已含“降低 3”的调整（相对初版 −0.05）。如需精确 −0.03 请改 `Define.AdrenalineHigh.MeleeHitReduction`。
